# Binary search sequence

Use the sorted list [2, 5, 8, 12, 19] and target 12.
Explain inclusive bounds: low=0, high=4, mid=2; 8<12, so low=3.
Next mid=3 gives 12. State that other midpoint conventions are valid when bounds are consistent.
Then ask the learner to search for 7 and explain termination; do not supply the practice answer yet.
