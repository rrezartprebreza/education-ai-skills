# Example request and plan

Request: a 50-minute introductory session on recursion; learners know functions and conditionals.

Objectives: trace a recursive call; identify a base case.
Agenda: 5-minute prerequisite check, 10-minute traced example, 12-minute paired tracing,
13-minute independent practice, 5-minute explanation of misconceptions, 5-minute exit question.
The exit question asks for a trace and base-case explanation, not just the final number.
Keep worked answers in instructor notes. Total: 50 minutes.
