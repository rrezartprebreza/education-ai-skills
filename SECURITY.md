# Security and educational privacy

Do not include credentials, student records, unpublished exam material or private answer keys
in issues or pull requests. Use GitHub's private vulnerability reporting when enabled, or
contact the maintainer through the linked professional profile to arrange an appropriate channel.
Do not send sensitive artifacts in an initial message.

This repository is not an LMS, access-control system, plagiarism detector or certified assessment
platform. Its static website has no upload form, account system, analytics or model API.
Installing a bundle does not grant consent to share private files with an AI provider.

For a suspected leak, stop further sharing, preserve necessary evidence in approved restricted
storage, and involve the responsible institutional contact. Deleting a public file does not
erase its Git history or previously downloaded copies.
